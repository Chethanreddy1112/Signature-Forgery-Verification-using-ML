# Signature Forgery Verification using Machine Learning

Signature Forgery Verification is a Machine Learning-based project designed to identify whether a signature is **genuine** or **forged** using image processing and classification techniques. The system analyzes signature patterns and features to improve authentication accuracy and reduce fraud.

## 🚀 Features

* Detect genuine and forged signatures
* Image preprocessing and enhancement
* Feature extraction from signatures
* Machine Learning-based classification
* Real-time signature verification
* User-friendly interface

## 🛠️ Technologies Used

* Python
* OpenCV
* TensorFlow / Scikit-learn
* NumPy
* Matplotlib
* Machine Learning Algorithms

## ⚙️ How It Works

1. Upload signature image
2. Preprocess the image
3. Extract important signature features
4. Train and classify using ML model
5. Display verification result
